RoachGrid is starting…

If this message stays visible, the React source has been opened without Vite (for example using VS Code Live Server).

Option 1 — edit and develop

Open a terminal in the folder containing package.json, run npm ci, then npm run dev. Open the Vite URL printed in the terminal, normally http://localhost:5173.

Option 2 — use Live Server

Open the included ready-to-run website, or right-click ready-to-run/index.html in VS Code and choose “Open with Live Server”. No npm install is needed for that version.

Do not double-click the HTML file to use a file:// URL. Read START_HERE.md for full steps.
